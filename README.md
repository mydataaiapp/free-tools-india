## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | HTML5, CSS3, JavaScript |
| **AI APIs** | Groq (Primary), Gemini (Backup) |
| **Database** | Supabase (PostgreSQL) |
| **Hosting** | Vercel |
| **Domain** | freetoolindia.com |
| **Email** | ImprovMX + Gmail |

## 🔒 Security Features

- ✅ API keys in Vercel Environment Variables
- ✅ Multi-API auto-fallback (4 APIs)
- ✅ Supabase Row Level Security (RLS)
- ✅ Security headers (X-Frame-Options, CSP)
- ✅ Input validation
- ✅ Spam protection
