Frequently Asked Questions

Can I compress an image to a specific size like 100 KB or 50 KB?

Yes. Our Target Size mode lets you set any file size limit (e.g., 100 KB, 50 KB, 200 KB). The tool automatically finds the best quality that fits your target. If the target cannot be reached, we tell you honestly — just like paid tools.

Does it support batch processing for multiple images?

Yes. Drop multiple images at once. The tool compresses them all and bundles the results into a single ZIP file for download. No limits on how many images you can process.

Are my images uploaded to a server?

No. All compression happens entirely in your browser using the Canvas API. Your images never leave your device. This is more private than most paid tools, which upload files to their servers.

What image formats are supported?

JPEG, PNG, and WebP. These cover almost all use cases. If you need format conversion, our tool handles it during compression.

Is there a limit on file size or number of images?

No. Unlike paid tools that cap free usage, we have no limits. Compress as many images as you want, as often as you want. It's free forever.

Will compressing reduce my image quality?

Our smart compression minimizes visible quality loss. You can choose a quality level (70–80% is ideal for web use) or let Target Size mode find the best balance. For most uses, the compressed image looks identical to the original.
